# Zapretka-Telegram-1.1
Обход блокировки Telegram в России. Программа на WinDivert для DPI-обхода.

> Утилита для обхода блокировки Telegram в России через WinDivert

## 📦 Файлы

| Файл | Для чего |
|------|----------|
| `Zapretka.exe` | Запуск программы |
| `WinDivert.dll` | Фильтрация сетевых пакетов |
| `general.dll` | Логика обхода блокировки |

## 🚀 Быстрый старт

1. Скачай все 4 файла в одну папку
2. Нажми правой кнопкой на `Zapretka.exe` → **Запуск от имени администратора**
3. Telegram заработает через пару секунд

## 🧠 Как работает

Перехватывает и модифицирует пакеты Telegram так, чтобы DPI провайдера не узнавал трафик.

## ⚠️ Антивирусы

Приложение ZapretkaTelegram может вызывать ложные срабатывания. Добавь папку с программой в исключения.
